
## Requirements

- Node.js 20 or newer
- Git
- Visual Studio Code or another code editor

## How to run the assignment

### 1. Clone your fork

```bash
git clone https://github.com/YOUR-USERNAME/js-data-types-assignment.git
cd js-data-types-assignment
```

### 2. Install dependencies

```bash
npm install
```

This project uses Node.js built-in testing tools, so no extra npm packages are required.

### 3. Complete your assignment

Open `assignment.js` and complete every TODO.

### 4. Run your JavaScript file

```bash
node assignment.js
```

### 5. Run the tests

```bash
npm test
```

All tests should pass when the expected behavior is correct.

### 6. Submit your work

```bash
git add assignment.js
git commit -m "Complete JavaScript data types assignment"
git push origin main
```

Submit the URL of your forked GitHub repository to your instructor.
