## 1. Introduction

Welcome to the JavaScript Data Types Practical Assignment!

In this assignment, you will explore the different data types available in JavaScript and understand how they are used when developing applications.

Data types define the kind of values that variables can store and how JavaScript handles those values.

You will practice writing JavaScript code, declaring variables, creating objects, working with arrays, defining functions, and checking data types.

This assignment is designed to help you develop practical programming skills through hands-on exercises.

## 3. JavaScript Data Type Categories

JavaScript data types are grouped into two major categories.

### A. Primitive Data Types

Primitive data types represent individual values.

The seven primitive types are:

1. Number
2. String
3. Boolean
4. Null
5. Undefined
6. Symbol
7. BigInt

### B. Non-Primitive Data Types

These are commonly called reference types.

For this assignment, we will practice:

1. Object
2. Array
3. Function
4. Date Object
5. Regular Expression (RegExp)
